Blinkit Sales Analysis

This project analyzes retail sales performance for Blinkit using Power BI dashboards. The dashboard explores outlet sales, item categories, and outlet performance metrics. Through visual analysis of key KPIs such as total sales, item counts, and ratings, the dashboard reveals patterns in product demand and outlet distribution. The analysis highlights high performing outlets and identifies which product categories generate the highest revenue.

Mobile Verse Analytics

The Mobile Verse Analytics project analyzes smartphone sales performance and customer purchasing behavior using interactive dashboards. The analysis focuses on identifying the top-performing mobile brands, understanding customer ratings, and evaluating payment preferences used during purchases. The dataset includes information about mobile models, brands, sales transactions, and customer ratings. Using Power BI, the data was cleaned, transformed, and visualized into meaningful dashboards that allow users to explore brand performance in detail. Key visualizations include brand-wise sales comparison, payment method distribution, and customer rating analysis. These insights help businesses understand which mobile brands are generating the highest sales and how customers interact with different products in the market.

Insurance Sales & Claims Analysis

This project analyzes insurance policy sales and claim trends using SQL and Python. The dataset contains information about policy premiums, claim costs, policy categories, and claim frequency across different time periods. SQL was used to extract and aggregate data to calculate important metrics such as total premium revenue, total claim cost, and claim ratios. Python libraries such as Pandas and Matplotlib were used to analyze trends and create visualizations that highlight claim cost patterns. The analysis focuses on understanding how claims impact insurance profitability and identifying periods where claim costs increase significantly. By comparing premium revenue against claim liabilities, this project demonstrates how data analysis can help insurers better understand financial risk exposure.
