Financial Dashboard

This project focuses on performing a complete end-to-end financial data analysis to evaluate business performance across multiple dimensions including regions, departments, and time. The goal was to simulate a real-world business scenario using a large dataset. A dataset of over 100,000 records was generated using Python, ensuring realistic representation of financial transactions. It included attributes such as revenue, expenses, profit, regions, and departments. This dataset allowed deep analysis across multiple business dimensions. The data was then imported into PostgreSQL where SQL queries were used to clean, structure, and analyze the data. Aggregations helped derive key KPIs such as total revenue, total expenses, and total profit. Grouping functions enabled performance comparisons across regions and departments. The analysis revealed which regions contributed most to profitability and which departments operated efficiently. Monthly trend analysis was conducted to identify patterns and fluctuations, helping understand seasonal impacts. Power BI was used to build an interactive dashboard presenting insights visually. KPI cards displayed revenue, profit, expenses, and margin. Bar charts compared regions and departments, while line charts tracked monthly trends. Interactive slicers allowed filtering by region, department, and time, enabling dynamic analysis. This improved user experience and made insights more accessible. Key findings showed consistent high performance from certain regions, while others had fluctuating trends. Departments showed relatively stable performance, indicating balanced operations. This project demonstrates strong skills in Python for data generation, SQL for data manipulation, and Power BI for visualization. It highlights the ability to convert raw data into meaningful insights that support business decision-making. Overall, this project reflects a complete data analytics workflow and showcases analytical thinking, technical skills, and visualization expertise.
