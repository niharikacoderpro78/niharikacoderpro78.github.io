Blinkit Sales Analysis

Project Overview

This project analyzes Blinkit retail sales data using Power BI dashboards to identify outlet performance, product demand, and revenue trends.

Tools Used

  • Power BI
  • Excel
  • Data Visualization

Key Insights

  • Identified top performing outlet locations
  • Analyzed sales by outlet size
  • Evaluated product category contribution to total revenue
  • Created an interactive dashboard for decision making
